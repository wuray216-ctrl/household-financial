# AI家庭资产负债表

面向公众号读者的家庭财务健康与房贷压力测试工具。

## 主要功能

- 家庭收入、资产、负债、保障与教育支出体检
- 房贷压力测试：当前现金流可撑多久、收入下降30%后的安全边际、30/40年展期情景比较
- AI个性化解读
- 基础测算在浏览器本地完成
- 仅在用户主动点击“生成AI解读”时，发送脱敏后的财务指标到后端

## 本地运行

前端：

```bash
npm install
npm run dev
```

后端：

```bash
cd server
npm install
cp .env.example .env
# 编辑 .env，填入模型地址、模型名和 API Key
npm start
```

前端默认调用同源 `/api/analyze`。本地开发可设置：

```bash
VITE_API_URL=http://localhost:3001 npm run dev
```

## 生产部署

推荐：前端静态站 + 独立 Node 后端 + 自有域名。

不要把 LLM API Key 放进前端代码。

## 隐私说明

基础测算不上传原始填写数据。AI解读只提交分析所需的脱敏指标，不收集姓名、手机号、身份证或精确地址。

## 免责声明

房贷展期、延期还本等是否适用，以银行、监管规则及实际合同为准。本工具仅做情景分析，不构成投资、信贷、法律或税务建议。


## 公众号上线建议

1. 前端部署到 HTTPS 域名；公众号文章放域名链接或二维码。
2. 后端单独部署，并把 `LLM_API_KEY` 只放在服务器环境变量。
3. 设置 `ALLOWED_ORIGINS` 为正式前端域名，避免任意网站盗用 AI 接口。
4. 默认每个 IP 每小时最多 20 次 AI 分析，可通过 `RATE_LIMIT_PER_HOUR` 调整。
5. AI 解读前会二次确认数据发送；基础财务计算仍在浏览器本地完成。
